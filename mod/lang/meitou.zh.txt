tip.Off = Meitou 自己的镜头。
tip.Free = Meitou 自己的操作，不锁定任何东西，可叠加偏移、荷兰角和 0.5x 镜头。
tip.Diorama = 像俯看桌上模型一样的高倾角（HD-2D 风格）。可自由旋转和缩放。
tip.DioramaLow = 你保存的低角度（Shift+J 或"保存为低角度"）。
tip.Isometric = 远距离加窄镜头：扁平的 CRPG 风格。停在四个对角方向。
tip.PixelIsometric = 30 度的等距，经典像素画角度。
tip.TopDown = 几乎垂直向下，像地图一样。
tip.SideView = 低位侧面，扁平镜头，像 2.5D 游戏。停在 90 度的方向上。
tip.Profile = 侧视镜头保持在镜头所跟随角色的侧面，随角色转动。
tip.HipLevel = 在镜头所跟随角色正前方的水平镜头，随角色转动。为拍摄披风而做。
tip.Turntable = 让视角绕圈旋转。自己转动镜头会暂停它。
tip.Chase = 转到镜头所跟随角色的身后（按 F 跟随角色）。
tip.Cinematic = 依次播放其他所有镜头。

tog.WideLens.on = 0.5x 镜头：开
tog.WideLens.off = 0.5x 镜头：关
tip.OffCentre = 把镜头横向移开，让角色不在画面中央，可叠加在任何镜头上。
tip.Dutch = 让画面倾斜几度，可叠加在任何镜头上。
tip.WideLens = 像手机 0.5x 一样的超广角镜头，可叠加在任何普通镜头上。

tiprow.ProfileSide = 0：侧身镜头留在当前一侧；1 或 -1：总在那一侧。

help.1 = PZA 镜头为 Meitou 的镜头提供固定的风格。在"镜头"页选一个镜头；再次点击当前镜头即可关闭。仍可像平常一样旋转和缩放。
help.2 = 微缩景观保持像俯看桌上模型的高倾角。等距、像素等距和侧视从远处用窄镜头拍摄（像 CRPG 一样扁平），并停在固定方向。俯视几乎垂直向下。
help.3 = 侧身、腰部高度和追随会随镜头所跟随的角色（F）转动，没有则随第一个选中的角色。转台让视角绕圈。电影依次播放各个镜头。
help.4 = 偏移、荷兰角和 0.5x 镜头可叠加在任何镜头上。Shift+J 把看到的倾角保存为"微缩景观（低）"；5 秒内再按一次撤销。
help.5 = 设置：- 和 + 立即改变数值，"重置"恢复它。所有数值也在 设置 > 模组 > PZA's Camera 中。
help.6 = 在 Meitou 的自由镜头（;）、拍照模式（P）、电影（F6）、小队飞行和 PZA's WASD Control 的视角中，它会自动让开。
help.7 = Shift+K 打开或隐藏此窗口。右上角的 - 或双击标题会把它缩成小按钮：点击它关闭镜头或重新打开，双击或按它的 + 打开窗口，拖动可移动，鼠标滚轮调整透明度。

tip.ts.Diorama = 微缩景观模糊（与微缩景观镜头搭配）。
help.8 = 移轴："关闭"、"微缩"、"HD-2D"和"微缩景观"设置 PZA's Looks 的移轴模糊（与它设置页上的是同一项）。没有安装 PZA's Looks 时，这一行为灰色。

row.YawStep = 微缩停靠 {1}
row.IsoYawStep = 等距停靠 {1}
row.KeepInViewMaxTilt = 可见抬高 {1}
tiprow.YawStep = 停止转动后，微缩景观停在这么多度的整数倍方向上（45：每个对角和侧面；0：自由）。
tiprow.IsoYawStep = 等距从对角方向起，停在这么多度的整数倍方向上（45：每个对角和侧面）。
tiprow.KeepInViewMaxTilt = 镜头拉近之前，"保持可见"最多把视角抬高多少度。
look.on = 微缩风格：开
look.off = 微缩风格：关
tip.look = 微缩景观镜头加上 PZA's Looks 的微缩景观移轴。关闭后恢复你原来的移轴。
help.9 = 视角：缩放档位把滚轮锁定在每个镜头的三个距离上；要设置自己的档位，先关闭它，缩放到想要的位置，再按"近"、"中"或"远"。山坡挡住角色时，"保持可见"会先抬高视角，再拉近镜头。
help.10 = 停靠步长让镜头在你停止转动后停在固定方向：45 停在每个对角和侧面。微缩风格是微缩景观镜头加上 PZA's Looks 的微缩景观移轴。
